This website is run by the FROST project at Ghent University. We want you to be able to use it without being tracked.

**What we do not do.** This site does not use analytics, advertising or tracking cookies, and it has no contact forms or user accounts. We do not collect personal data through this website.

**Fonts.** The fonts are stored on this website itself, so your browser does not contact third-party font services.

**Maps.** Pages with an interactive map load map tiles from [OpenFreeMap](https://openfreemap.org/), a free service based on OpenStreetMap data. When those pages load, your browser connects to OpenFreeMap's servers, which may see your IP address, as with any website request.

**Hosting.** The site is hosted on GitHub Pages. GitHub may log technical information such as IP addresses for security purposes; see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

**Email.** If you email us, we use your message only to reply to you.

**Questions.** For questions about privacy, contact us via the [Contact](../contact/) page or Ghent University's data protection officer.
